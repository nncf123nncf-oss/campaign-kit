# キャンペーン告知セット（campaign-kit）

店名とキャンペーン名を入れると、店頭に貼るA4・Instagram投稿・ストーリーズ・LINEリッチメッセージの4つが同じデザインで一度にできます。

100日100プロダクトチャレンジ Day045。

## 使い方

1. キャンペーン名（14文字まで）・店名（16文字まで）を入れる。期間・一言は任意
2. デザインを選ぶ（業種5種 × 雰囲気2種の10種類）
3. 写真を入れると上半分が写真になる（任意・1枚・8MBまで）
4. 「3枚まとめて保存」でInstagram投稿・ストーリーズ・LINE用のPNGを保存、「店頭A4を印刷」で印刷画面を開く

## 出力形式と根拠

| 形式 | 寸法 | 根拠 |
|---|---|---|
| 店頭A4 | 210×297mm（2480×3508px相当） | 印刷用 |
| Instagram投稿 | 1080×1440（3:4） | Instagramヘルプセンター「Instagramでシェアする写真の画像解像度」の対応範囲 1.91:1〜3:4（幅1080）の上限 |
| ストーリーズ | 1080×1920（9:16） | Meta広告ガイド「Instagramストーリーズ 画像広告の仕様」の比率9:16と安全域（上14%・下35%・左右6%）に合わせた |
| LINEリッチメッセージ | 1040×1040 | LINE公式アカウントマニュアル「リッチメッセージ」の正方形テンプレート（10MB以下） |

Instagram用の正方形とX用の横長は、上の形式と用途が重なるため作っていません。

## 技術

- HTML / CSS / JavaScript（1ファイル）＋ `assets/templates/` の背景画像（WebP・20枚）
- 描画はCanvas。保存はPNG、A4は `@media print` でブラウザの印刷ダイアログから出力
- 入力した文字・写真はブラウザの中だけで扱い、送信・保存しません
- ページの閲覧数のみ Cloudflare Web Analytics で計測しています（入力内容は送りません）
- 背景画像は制作時に画像生成AI（fal.ai / nano-banana-2）で作成し、同梱しています。生成に使ったプロンプトは `assets/prompts/` にあります。実行時にAIは使いません

## 作らないもの

フォント選択、色の自由指定、ロゴ配置、保存機能、テンプレの追加、QRコード、クーポンの面付け、X用横長、Instagram正方形

## 動作確認

- 保存PNGの寸法（1080×1440／1080×1920／1040×1040）とA4印刷（1ページ・A4サイズ）は headless Chrome で確認
- iPhone Safariでは保存ボタンで画像が新しいタブに開く場合があります。長押しで保存してください
